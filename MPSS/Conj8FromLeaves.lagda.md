# MPSS: Conjecture 8 from the chains at the narrowed leaves

`MPSS/Conj8Reduction` gives `conj8 : StepLift → Conj-8`, and `MPSS/Conj8Push` reduces `StepLift`
to two obligations over spines, `FunLift` and `FOpLift`. This module reduces it instead to **one**
obligation in the form the recursion can use (`MPSS/CONJ8.md` §9–10): for a class `𝒫` of side
conditions that is closed under the application and binder wrappers and contains
"`z` applied to `v` is well-formed", the supplier `NewLeaf` of `MPSS/Annotate` —

> when an abstraction `λx≤t.u` meets an operand `α`, a chain `α ◁* t` at any stack of any
> extension of `x ≡ α, Γ`, under any side condition of the class that holds at `t`.

`FOpLift` has disappeared: an abstraction the derivation already enters under an operand is
structural (`q-fop`). `FunLift` has become the supplier, and the supplier is Conjecture 8 again —
at the pair (operand, annotation), in stack form, in the narrowed context — which is what makes an
induction on the rank of the annotation possible (`MPSS/DomainOrder`).

Nothing existing is modified.

```agda
{-# OPTIONS --safe #-}

module MPSS.Conj8FromLeaves where

open import Data.List.Base using (List; []; _∷_; _++_)
open import Data.Product.Base using (_,_)
open import Data.List.Membership.Propositional using (_∈_; _∉_)

open import MPSS.WellFormed
open import MPSS.Narrow using (wf-fv)
open import MPSS.Frame using (App; Wf; ◁*-app; ◁*⇒≤*wf)
open import MPSS.Wrap using (Fun)
open import MPSS.Annotate
open import MPSS.Conj8Reduction using (StepLift; conj8)
open import MPSS.Assumed using (Conj-8)

module _ (𝒫 : Ctx → Stack → (Tm → Set) → Set₁)
         (𝒫-app : ∀ {Γ s P v} → 𝒫 Γ s P → 𝒫 Γ (v ∷ s) (App P v))
         (𝒫-fop : ∀ {Γ s P α t x} → 𝒫 Γ (α ∷ s) P → x ∉ dom Γ
                → 𝒫 ((x , eqv , α) ∷ Γ) s (Fun P t x))
         (𝒫-fun : ∀ {Γ P t x} → 𝒫 Γ [] P → x ∉ dom Γ
                → 𝒫 ((x , sub , t) ∷ Γ) [] (Fun P t x))
         (𝒫-top : ∀ {Γ v} → Γ ⊢ v wf → 𝒫 Γ (v ∷ []) (App (Wf Γ) v))
         (new-leaf : NewLeaf 𝒫 𝒫-app 𝒫-fop 𝒫-fun)
         where

  ▶ᴸ-refl : ∀ Γ → _▶ᴸ_ 𝒫 𝒫-app 𝒫-fop 𝒫-fun Γ Γ
  ▶ᴸ-refl []      = l-nil
  ▶ᴸ-refl (e ∷ Γ) = l-keep (▶ᴸ-refl Γ)

  steplift : StepLift
  steplift {Γ} {a} {a'} {v} wa d wa' wav@(Wf-App _ d₂) wa'v =
    ◁*⇒≤*wf (◁*-app (push-from-leaves 𝒫 𝒫-app 𝒫-fop 𝒫-fun new-leaf (v ∷ [])
                        (▶ᴸ-refl Γ) (wf⇒lc wa) (wf-fv wa) d (𝒫-top wv) pv wav wa'v))
    where
      wv = ⊑*wf⇒wfˡ d₂
      pv : Γ ∣ (v ∷ []) prevalid
      pv = Pv-Sta (Pv-Nil (wf⇒prevalid wv)) (wf⇒lc wv) (wf-fv wv)

  conj8-from-leaves : Conj-8
  conj8-from-leaves = conj8 steplift
```

## What this establishes

`conj8-from-leaves`: Conjecture 8 from `NewLeaf`, for any wrapper-closed class of side conditions
that contains well-formedness of the applied term. The proof uses nothing about the class; the
class is where a proof of `NewLeaf` keeps what it needs — the rank of the annotation, and the
facts that put the points of a lifted chain inside the side condition.

## The class that is actually needed, and the obligation that is left

The side conditions the recursion meets are the ones generated from the top one by the two
wrappers, and nothing else. With the class taken to be exactly those, its closure properties are
its constructors, and what is left of Conjecture 8 is one type.

```agda
data 𝒲 : Ctx → Stack → (Tm → Set) → Set₁ where
  w-top : ∀ {Γ v} → Γ ⊢ v wf → 𝒲 Γ (v ∷ []) (App (Wf Γ) v)
  w-app : ∀ {Γ s P v} → 𝒲 Γ s P → 𝒲 Γ (v ∷ s) (App P v)
  w-fop : ∀ {Γ s P α t x} → 𝒲 Γ (α ∷ s) P → x ∉ dom Γ → 𝒲 ((x , eqv , α) ∷ Γ) s (Fun P t x)
  w-fun : ∀ {Γ P t x} → 𝒲 Γ [] P → x ∉ dom Γ → 𝒲 ((x , sub , t) ∷ Γ) [] (Fun P t x)

-- what is left of Conjecture 8
Obligation : Set₁
Obligation = NewLeaf 𝒲 w-app w-fop w-fun

conj8-from-obligation : Obligation → Conj-8
conj8-from-obligation = conj8-from-leaves 𝒲 w-app w-fop w-fun w-top
```

`Obligation` unfolded: for a side condition `P` generated by the wrappers at `Γᵉ ∣ α ∷ s′`, that
holds at `λx≤t.u` and at `λx≤t.u′`, and a fresh `x` — for every extension `Γ′` of `x ≡ α, Γᵉ`,
every stack `σ` and every generated `P′` at `Γ′ ∣ σ` that holds at `t`, a chain
`Γ′ ∣ σ ⊢[ P′ ] α ◁* t`.
